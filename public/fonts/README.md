# Licensed fonts

Helvetica Now Display is a Monotype font and is not included in this repository.
Add the licensed web font files here with exactly these names:

- HelveticaNowDisplay-Medium.woff2 (weights 500 to 600)
- HelveticaNowDisplay-Bold.woff2 (weight 700)
- HelveticaNowDisplay-ExtraBold.woff2 (weights 800 to 900)

Check that your licence covers web embedding. Until the files are here, headings use
Helvetica Neue, Helvetica or Arial.
